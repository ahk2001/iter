# Autoescuelas ITER — Fuente Álamo y Cartagena 🚗🇪🇸

Sitio web oficial y landing page de alta conversión para **Autoescuelas ITER** (Auto Escuela Iter S.L. / Iter Formación), centro homologado por la DGT con 4 sedes operativas en **Fuente Álamo de Murcia** y **Cartagena** (Región de Murcia, España).

🌐 **Demo Online (GitHub Pages):** [https://ahk2001.github.io/iter/](https://ahk2001.github.io/iter/)  
📦 **Repositorio Oficial:** [https://github.com/ahk2001/iter](https://github.com/ahk2001/iter)

---

## 🌟 Características Principales

- **Diseño Ultra-Moderno & Automotriz:** Estética oscura, sobria y premium con paleta oficial de señalización vial (Rojo Tráfico `#DC2626`, Verde Semáforo `#22C55E`, Amarillo Señal `#F59E0B` y fondo Asfalto `#0C0E14`).
- **100% Responsive (Desktop & Mobile First):**
  - **Desktop:** Barra de navegación superior fija (`sticky`) con logo semafórico corporativo, enlaces directos a secciones y botón de WhatsApp. Secciones de ruta y preguntas frecuentes con efecto *Pinned/Sticky Intro* balanceado en 2 columnas.
  - **Mobile:** Menú hamburguer nativo ultraligero con drawer a pantalla completa, enlaces de navegación, botón de matriculación y tarjeta con las **4 Sedes Físicas** con marcación telefónica directa a un clic.

## 🚀 Cómo Visualizar Localmente

Basta con abrir el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox o Safari):
1. Haga doble clic sobre `index.html` en el explorador de archivos; o
2. Arrastre el archivo `index.html` hacia una pestaña abierta del navegador.

## 🌐 Despliegue en GitHub Pages

Para publicar el sitio en GitHub Pages:
1. Vaya a la pestaña **Settings** del repositorio en GitHub: `https://github.com/ahk2001/iter/settings/pages`.
2. En la sección **Build and deployment > Source**, seleccione **Deploy from a branch**.
3. En **Branch**, elija la rama `main` y la carpeta `/(root)`.
4. Haga clic en **Save**. En 1 a 2 minutos el sitio estará disponible en:
   👉 **`https://ahk2001.github.io/iter/`**
